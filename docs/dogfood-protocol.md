# Dogfood 测试协议

## 测试目标

用 StoryForge3 写《我是路人甲》的下一章真实内容，验证引擎在真实创作场景下的表现。目标不是证明系统“能跑”，而是发现真实作者使用时的阻塞、误判、等待、困惑和质量问题。

## 前置条件

- `storyforge3 serve` 正在运行
- Web UI 可访问：`http://localhost:5173`
- 《我是路人甲》书籍已创建，或已有存量数据可继续使用
- AI 提供商已配置且连通
- 测试者愿意记录失败，不用手动美化结果

## 执行步骤

1. 打开 Web UI，进入《我是路人甲》。
2. 选择下一个未写章节。
3. 执行 `plan`，记录规划质量、目标清晰度、上下文完整性。
4. 执行 `draft`，记录字数、耗时、文风一致性、角色区分度。
5. 执行 `audit`，记录规则命中、误判率、阻断问题。
6. 如需 `revise`，记录修订模式选择是否合理、修订效果是否改善。
7. 执行 truth 提取或完整管线中的 truth 步骤，记录提取质量、遗漏和错误。
8. 执行 export，记录格式正确性。
9. 保存最终章节文本、审计结果、truth 摘要和导出文件路径。

## 判定标准

- **可继续使用**：能完成一章，人工只需做正常编辑，不需要绕过系统流程。
- **需要修复后再用**：流程能跑完，但有严重误判、状态混乱、保存/导出不可信等问题。
- **阻断**：无法启动、无法配置 provider、无法生成正文、正文丢失、导出失败或关键操作无反馈。
